接口参数注释

参数名说明类型必选
num提取ip数量int是
format返回数据格式分割符，n = \n rn = \r\nint是
time轮转时长（分钟，粘性会话）string否
type数据格式: txt jsonstring否
sid粘性会话ID（相同sid提取到同一出口IP）string否
ip_modeip6（默认，独立 IPv6）或 ip4（共享 IPv4 NAT，默认自动去重）string否
unique_ip仅 ip4 生效：默认去重，传 0 可关闭；去重后数量可能少于请求值int否

返回示例

192.6.121.16:11010 192.6.121.16:11011 192.6.121.16:11012
txt 每行一条 IP:端口（白名单端口，免密直连）；json 返回结构化数据（含账密与出口IP）。
提取说明：IPv6（ip6）每个实例通常拥有独立出口；IPv4（ip4）来自共享 NAT 池，默认自动按 IPv4 去重，实际返回数量可能少于请求数量。需要按实例提取时可在链接后加 &unique_ip=0。
注意：白名单内IP免密直连代理白名单端口（实例端口+1000）并免Key调用全部API；服务器本机始终放行。

创建 / 重建 WARP 实例

单容器内运行的独立 WARP 实例数，每个实例有独立 IP
单容器多实例: 1 个 Docker 容器内运行 N 个独立 WARP 实例。
每实例独立注册获得独立 IP，换 IP 无需重建容器。
端口范围: 10001 ~ 10020，创建后自动检测 IP 并去重。

编辑白名单

添加白名单

白名单内IP将免Key调用全部API，并免密直连代理白名单端口（实例端口+1000）。提交后自动查询归属地。

提取并使用 IP

绑定后锁定实例当前 IPv6 出口：不参与轮换、豁免所有自动换IP，直到解绑。
白名单外请用账密连接（提取后可在列表中复制）；白名单内可用免密端口（端口+1000）。
